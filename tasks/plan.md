# 实现计划：运输船 · 3D 浏览器枪战

## 视觉系统
- 色彩：深海石墨 `#0b1115`、钢铁雾灰 `#93a4ac`、舰漆白 `#e7edef`、安全橙 `#f2b544`、友军青 `#58b7d1`、敌军红 `#e56b60`。
- 字体：Barlow Condensed 用于标题和关键数字，IBM Plex Mono 用于战斗数据，中文使用系统黑体。
- 构图：实时 3D 舰船为全屏背景；开始页左侧是任务简报和主要操作，右侧保留战场视野。游戏内 HUD 沿屏幕边缘布置，中央只保留准星与即时反馈。
- 原则：工业化直角与切角、克制的线条、无装饰性卡片堆叠；动态只服务于后坐力、命中、受伤与状态变化。

## 组件与依赖
1. **工程基础**：Vite、Three.js、本地字体、静态资源路径。
2. **世界 `world.js`**：甲板/船体、出生建筑、集装箱、木箱、护栏、海面、天空、光照、碰撞盒、射线检测、导航网格。
3. **玩家 `player.js`**：指针锁定、键鼠输入、重力、跳跃、蹲伏、冲刺、碰撞和相机反馈。
4. **武器 `weapons.js` + `effects.js`**：M4A1 / AK-47 / Desert Eagle，射速、扩散、后坐力、伤害、换弹、瞄准、枪口火光、弹道、弹孔与弹壳。
5. **战斗 `bots.js` + `game.js`**：4v4 团队对抗，视线/遮挡、A* 寻路、反应与命中率、死亡重生、比分、计时和结算。
6. **表现 `ui.js` + `audio.js` + `styles.css`**：任务简报、HUD、小地图、击杀信息、暂停与结算，以及空间枪声和环境音。
7. **验证与发布**：Node 逻辑测试、生产构建、ego-browser 实际交互/截图、CDN 公开地址复验。

## 风险控制
- **性能**：共享/合并集装箱几何、限制像素比和阴影、弹孔/粒子使用有界池、AI 分帧更新。
- **碰撞**：静态世界使用 AABB；命中统一比较最近静态与角色交点，避免隔墙射击。
- **寻路**：在约 1 米导航网格上运行 A*，仅在目标变化或定时刷新时计算，避免每帧搜索。
- **指针锁**：开始/恢复必须由用户点击触发；Esc 和失焦进入暂停，不让游戏在后台继续伤害玩家。
- **移动端**：保持菜单与 HUD 响应式，明确提示完整战斗需要键鼠。

## 验证检查点
- 世界完成后：浏览器能看到地图且无渲染错误。
- 战斗完成后：移动、开火、命中、阵亡、重生、计分均改变真实状态。
- 表现完成后：桌面和窄屏截图无溢出，菜单键盘可操作，减少动态设置生效。
- 发布后：从 HTTPS 地址重新加载，资源无跨域/路径错误，核心流程可执行。
