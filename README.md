# 运输船 · BLACKWATER

一个无需后端、可直接在现代桌面浏览器中运行的 3D 第一人称团队枪战。以经典运输船的双端出生区、三线甲板与中央集装箱交接区为灵感，全部舰船、人物、枪械、材质和音效均由代码生成，不包含官方游戏资源。

## 游玩内容

- 4 对 4 团队竞技：玩家与 3 名友军，对抗 4 名战术 AI
- M4A1、AK-47、Desert Eagle 三种武器
- 射速、弹匣、备弹、换弹、扩散、后坐力、机瞄和部位伤害
- AI 视线遮挡、反应时间、A* 寻路、走位、点射、阵亡与重生
- 真实碰撞和最近交点命中，不能隔着集装箱伤害敌人
- 生命、护甲、小地图、击杀信息、比分、计时、战绩与回合结算
- 程序化锈蚀金属、甲板、木箱、动态海面、光照与空间枪声
- 高 / 中 / 低画质，低画质关闭反射和阴影并简化 PBR 材质
- 标准 Pointer Lock 鼠标视角；受限浏览器自动使用自由鼠标后备模式

## 键位

| 操作 | 键位 |
|---|---|
| 移动 | W / A / S / D |
| 视角 | 鼠标移动 |
| 射击 | 鼠标左键 |
| 机瞄 | 鼠标右键 |
| 冲刺 | Shift |
| 跳跃 | Space |
| 蹲伏 | C 或 Ctrl |
| 换弹 | R |
| 切换武器 | 1 / 2 / 3 或鼠标滚轮 |
| 实时战绩 | 按住 Tab |
| 暂停 | Esc |

回合时长 4 分钟，先获得 30 次团队击杀的一方获胜；时间耗尽时按比分判定。

## 本地运行

需要 Node.js 22+ 与 pnpm。

```bash
pnpm install
pnpm run dev -- --host 127.0.0.1
```

打开终端显示的本地地址，点击“进入战场”。音频会在首次用户操作后启用。

## 测试与构建

```bash
pnpm test
pnpm run build
pnpm run preview -- --host 127.0.0.1
```

- `pnpm test`：伤害、护甲、射线、换弹、计时、随机数和武器数据的逻辑测试。
- `pnpm run build`：生成可部署到任意静态 CDN 的 `dist/`。
- `vite.config.js` 使用相对资源路径，可部署在域名根目录或 GitHub Pages 项目子路径。

## 代码结构

```text
src/world.js       舰船、地图、光照、海面、碰撞和导航
src/player.js      键鼠输入、移动物理、生命和护甲
src/weapons.js     武器模型、射击、后坐力、机瞄和换弹
src/bots.js        士兵模型、AI 感知、寻路与交战
src/game.js        统一命中、比分、重生和回合状态机
src/effects.js     弹道、弹孔、火花和弹壳
src/audio.js       程序化枪声、脚步、换弹与环境音
src/ui.js          菜单、HUD、小地图和战绩
src/main.js        渲染器与启动流程
```

## 运行建议

- 推荐支持硬件加速的最新 Chrome / Edge，并使用耳机。
- 完整操作需要键盘和鼠标；触屏设备仅提供页面与提示。
- 如果设备使用软件 WebGL，启动时会自动选择低画质；也可在“战术设置”中手动调整。
- 本项目是单人 AI 演训，不包含联网匹配、账号或服务器。
